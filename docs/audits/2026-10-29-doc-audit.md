wasm 的具体错误：

```text
e: composeApp/src/commonMain/kotlin/com/eimsound/eimusic/media/NotificationAudioPlayer.kt:7:1
   The 'expect' declaration 'NotificationService' has no 'actual' declaration in module '<commonMain> for wasm-js'.
e: composeApp/src/commonMain/kotlin/com/eimsound/eimusic/util/Logger.kt:3:1
   The 'expect' declaration 'log' has no 'actual' declaration in module '<commonMain> for wasm-js'.
```

因此 README 中的 `:composeApp:wasmJsBrowserDevelopmentRun` 当前会在编译阶段失败，而不是“可开发运行”。

另外，即使补上这两个 actual，wasm 启动仍会撞到数据库问题：

- `composeApp/src/commonMain/kotlin/com/eimsound/eimusic/App.kt:213` 用 `createdAtStart = true` 急切创建数据库；
- `composeApp/src/wasmJsMain/kotlin/com/eimsound/eimusic/data/Database.wasmJs.kt:6` 直接 `error("SQLite is not available on wasmJs...")`；
- `composeApp/src/wasmJsMain/kotlin/com/eimsound/eimusic/data/Storage.wasmJs.kt` 只是内存 Map，不持久化。

所以 README 的“Web 支持”不是“缺少一个 fallback”，而是当前 Web 目标编译不过、且启动路径会抛错。

### README 的主要缺口

1. **缺少 terminalApp 使用文档**：README 第 58-87 行只有构建命令，没有配置目录、设置页、键位、i18n、SQLite 数据库、更新检查、MPRIS 等说明。
   - 这些内容曾在 `e81cfab` 中加入 README，随后被 `4c20461` 回退；`TODO.md` 里还保留着对应信息。
   - 如果恢复，配置目录不能只写 `~/.config/eimusic/`：Linux 是 `~/.config/eimusic`，macOS 是 `~/Library/Application Support/eimusic`，Windows 是 `%APPDATA%\eimusic`（见 `terminalApp/src/*/kotlin/com/eimsound/eimusic/Platform.kt`）。
2. **配置示例缺失**：README 让用户复制 `eimusic.example.json`，但仓库没有这个文件；代码实际会自动生成默认 `eimusic.json`。应补示例文件，或把文档改成“首次运行自动生成，按需修改”。
3. **JDK 版本**：README 写 17+，但 server toolchain 和 CI 都是 25。应写 25，或明确“17+ 且允许 Gradle 自动下载 25 toolchain”。
4. **Release/更新检查的线上状态**：GitHub 仓库当前没有 Release/tag；README 把“Release 提供二进制”和“更新检查”写成既成事实。建议二选一：先发布 `v1.0.0`，或把 README 改成“配置为……发布后可用”。
